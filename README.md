## Work

### Agenda

Built out of survival. Between two internships, schoolwork, and club
commitments, my schedule lived in four places at once — and every tool I tried
solved one piece of it, with the rest behind a paywall.

Agenda pulls them together. It syncs with Google Calendar so events and tasks
share one view. It stores flashcards that sync across devices, which most
flashcard apps still charge for. It has a private log for notes that belong
next to the schedule rather than in a separate app.

The agent ties it together — it can create flashcards, schedule events, write
notes, and pull information across several of them to act on.
